    FCS files referenced by a workspace

    Windows S:/MK3/research/ → Mac /Volumes/research/. Link reads the SMB original directly without making a local FCS copy. The share must stay mounted for analysis and downloads. Analysis caches still use local storage. Name matches alone do not verify file identity.

    Link all includes all available files in this workspace, regardless of the search filter. Keep this tab open until finished. Completed links are retained if stopped; failed files can be retried.

    Export to FlowJo

    Download the WSP and original FCS into the same folder. Open the WSP in FlowJo v10 and reconnect the FCS if prompted. Only the selected sample's saved changes are applied; other samples and group templates are preserved and may need their original FCS files. Unsaved gate drafts are not exported.

    Compensation and transform settings are preserved. Export is checked by reimporting the WSP; verification in the FlowJo application is still pending. FlowJo may recalculate different event counts. WSP-free analyses are not yet exportable.

    New analysis

    WSP imports compensation, transforms and supported gates. Without WSP, acquisition coordinates are used. Mouse ID must be verified separately from FlowJo sample IDs.

    Preview limits: 2 million events and 50 million channel values per sample. Original files remain preserved.
